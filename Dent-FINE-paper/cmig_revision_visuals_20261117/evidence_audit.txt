4. CAM implementation: verified
A positive elementwise gradient-times-activation map is computed as
ReLU(sum_c A_c * d s / d A_c), retaining the spatial gradient, in HiResCAM form.
CMFA/HOOA before/after figure maps target the reference-FDI detector logit at the
finest encoder output. Each independently trained model's corresponding native
query is matched by its archived bounding box and native top-1 category; query
indices need not be identical across models or CPU/GPU arithmetic.
For the Prototype panel, the prototype map instead targets its actual auxiliary
reference-class score. Captures verify that recomputed logsumexp prototype scores
match model pred_proto_logits within 1e-6. The five displayed scores are the
highest supported-class auxiliary scores; no extra inference classifier is used.
All controlled CAM captures are CPU FP32, no AMP, strict EMA loading. Passive
hooks produced zero reference-logit difference from an unhooked pass.
Maps are computed on the full image, normalized individually by the full-image
positive maximum, bilinearly upsampled only for display, then identically cropped.
GT is used to choose/reference a tooth and for display/post-hoc diagnostics; no GT
spatial mask enters CAM computation. Native query-content initialization is detached,
so gradients describe the remaining differentiable paths. These maps are spatial
attribution, not native attention, segmentation, probability, or a cross-map
contribution-magnitude scale. No extra theoretical faithfulness guarantee is implied.

6. Factor-head occlusion: verified down to the raw arrays
Checkpoint is the same final Mobile seed-2 EMA. Each 1024x1024 input has a 128x128
sliding mean-color occluder at stride32: (1+(1024-128)/32)^2 = 29^2 =841 locations.
The patch is filled with that image's RGB channel means. All 841 perturbed inputs
are independently forwarded (batched by8), yielding one perturbation sweep per
image and responses for all three heads in the same forwards. It is NOT 841 new
forwards separately for each head. There are three displayed images, 2,523 perturbed
inputs total, plus baseline checks. The actual occlusion capture script runs GPU
FP32 with AMP/TF32 disabled; do not describe all visual diagnostics as CPU-only.
For each head h, s_h is correct-factor logit minus the strongest other logit in
the unperturbed input. Both the target and competitor indices remain fixed.
Delta_h(p)=s_h(x)-s_h(x with patch p). Positive/red means the occlusion reduces
the reference-factor decision margin; negative/blue means it increases that margin.
The unoccluded encoder top-k anchor indices/order are frozen, and the same query
index is evaluated throughout the sweep. Memory/query contents, decoder states,
factor logits and boxes are recomputed from each perturbed input. This is a
conditional-query input sensitivity experiment, not rerun-native-top-k detection
accuracy under occlusion. The unperturbed conditioned forward has exactly zero
maximum output-logit change relative to its native baseline.
Each pixel's map is the mean of the signed drops for all covering patches. The
three raw .npz files each contain exactly841 unique (x,y) locations and841 values
per head; recomputing every dense array from those patch values gave max error0.
No Gaussian smoothing or target spatial masking is used. Render uses nearest
interpolation and a symmetric diverging color scale shared ACROSS THE THREE CASES
WITHIN EACH HEAD, with separate scales for quadrant/position/dentition. Therefore
within-head values can be compared in logit-margin units, whereas shade alone
cannot compare magnitudes between heads with different scales.
Dashed boxes are GT locations, used for correspondence/display, not hotspot creation.
All nine largest-drop occluders intersect their respective GT boxes, though their
covered fractions vary; surrounding context is also perturbed. The position head
in image115/FDI64 has strong signed effects (+5.991 and -6.345 extrema), consistent
with both supportive and interfering context. Mean-color occlusion creates an
artificial input perturbation, so the map is sensitivity rather than a clinical
causal claim. See factor_occlusion_selected_cases.csv for exact reported margins.
