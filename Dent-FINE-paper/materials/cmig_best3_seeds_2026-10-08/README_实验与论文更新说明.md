## 2. 内部消融围绕本轮最佳完整配置展开

Mobile 使用本轮 `mobile_1024_full` 的 seed 0 作为完整模块参考。保留的 20 个内部配置由 CMFA 门控 3 个、HOOA 分支 3 个、因子监督移除 3 个、关闭训练因子融合 1 个、原型数量/温度/关闭原型 5 个、DualOpt 单操作 2 个、Mobile 背景损失 3 个构成。

组内设置规则不变：

- CMFA 关闭通道门时移除对应门控交叉残差，关闭空间门时使用恒等映射，保留输出维度。
- HOOA 移除指定高通或二阶交互分支，保留约定的 context 与投影结构。
- 因子监督移除组的训练与推理融合均关闭；参考是本轮 `internal_mobile_factor_train_off`，不是融合开启的完整模型。
- 原型数量指每个 FDI 类的原型个数；数量、温度和关闭原型均使用明确的单因素设置。
- Mobile 背景损失组固定完整模型的其他模块，只改变 NWD/arch-position 项。
- DualOpt 组固定 DSLR CMFA 架构，保持普通 AdamW weight decay 不变。新训练 `internal_dslr_cmfa_adamw` seed 0 提供“两个附加操作均无”的参考；rollback-only、extra-decay-only 和本轮完整 DSLR seed 0 构成其余三种设置。它不是新三种子 baseline。

因子训练融合 on/off 的两个 seed 0 checkpoint 各自做推理 on/off 重放，得到四格比较。两次反向开关评估必须使用对应权重的原生 FP32 输出；它们是同权重推理实验，不增加训练数。

## 3. Pano：三个最终权重上的四路先验重放

Pano 三种子均沿用历史 SpatialShape 完整原生配置，在训练循环的原生验证及最佳 checkpoint 选择中保留历史先验设置。不能用 prior-OFF 选中的另一个模型冒充历史 prior-ON 选模配方。本轮不再训练 Pano 四组辅助监督对照。

对每个最终冻结 checkpoint 分别执行无先验、仅中心、仅形状、中心+形状四路原生 FP32 评估，共 12 路推理重放。每个种子内权重、输入和候选框/类别输出来源相同；只切换声明的推理先验。四路隔离中心/形状时禁用 view/appearance 标志，保留冻结配置中的先验权重；完整配方的主结果仍按原生配置评估，不能仅凭名称假定两条路径完全一致。

## 4. 结果完整性与保存规则

论文 AP、AP50、AP75、AR100 使用冻结权重的原生 FP32 验证结果，并与原生选模记录严格核验。候选导出/固定阈值终点是次级分析路径，可能存在很小的浮点舍入差异；差异须保存，不能选择较高的一条充当论文主 AP。

每项任务必须保留完整配置、源码/数据/初始化校验信息、日志、最佳 epoch、原生指标和 provenance，以及最终 `best.pth`。原生阶段算法需要的临时 checkpoint 在训练期间照常使用，成功核验后才清理本任务的冗余阶段/last 权重；最终只保留最佳模型权重。不能为节省磁盘改变原生阶段重置或选模算法。

参数口径须一致。历史可训练参数与全部参数之间的 5 个差值来自冻结标量 `decoder.up`、`decoder.reg_scale` 和 `decoder.decoder.layers.{0,1,2}.gnn_gate`，不是新增五个可训练参数或架构漂移。完整 Mobile/DSLR/Pano 的历史可训练参数数目分别为 12,513,162 / 11,153,963 / 10,650,249；全部参数统计各多 5。

两张 GPU 使用负载均衡的独立串行队列，每卡同时只运行一个本轮任务。启动确认后助手不持续监控或定时轮询；自动 worker 负责哈希、磁盘余量、任务异常和评估一致性检查，失败时停止相应队列并记录原因，不自动改配方或覆盖半成品。

原数据划分保持不变，已知内容重叠及缺少独立测试集的限制继续披露；本轮结果是内部开发验证，不是独立测试性能。
